# 本地开发依赖环境部署

本地开发所需的依赖——**PostgreSQL**、**Redis**、**Meilisearch**——由仓库根目录的 `docker-compose.dev.yml` 统一提供，不再逐个手工 `docker run`。

## 一键起停

```sh
make deps-up      # 启动，并等待所有服务通过健康检查
make deps-status  # 查看容器状态
make deps-logs    # 跟踪日志
make deps-down    # 停止，保留数据卷
make deps-reset   # 停止并删除数据卷（重置数据库/缓存/索引）
```

## 服务与连接信息

| 服务 | 镜像（pin 确切 tag） | 宿主机地址 | 凭据 / 说明 |
| --- | --- | --- | --- |
| PostgreSQL | `postgres:18.6` | `127.0.0.1:5432` | user/password `paopao`，database `websitecore`；数据卷挂到 `/var/lib/postgresql`（PG18 的 PGDATA 位于其子目录） |
| Redis | `redis:7.4.11` | `127.0.0.1:6379` | 无密码，开启 AOF（`--appendonly yes`） |
| Meilisearch | `getmeili/meilisearch:v1.54.0` | `127.0.0.1:7700` | master key `paopao-meilisearch` |

- 端口只绑定到 `127.0.0.1`，不会暴露到局域网。
- 数据保存在命名卷 `websitecore-pgdata` / `websitecore-redisdata` / `websitecore-meilidata`。
- 镜像为确切 tag pin，避免环境漂移；升级某个依赖时需在此显式更新 tag。

## 配置与建库

依赖起来之后：

```sh
cp config.yaml.sample config.yaml
# 生成并填入 JWT.Secret（必填，留空启动会直接退出）：
openssl rand -hex 24
make migrate           # 用内嵌迁移脚本建出完整 schema
make build-web         # 构建前端产物（供 embed 内嵌）
make run TAGS='embed'  # 启动后端（内嵌前端）
```

`config.yaml.sample` 的连接信息已与 `docker-compose.dev.yml` 对齐，默认后端为 PostgreSQL，无需手工修改。

## 其它可选依赖

对象存储仅支持 LocalOSS 和 AliOSS。本地开发默认使用 LocalOSS；AliOSS **不在**默认 dev compose 内，使用时需在 `config.yaml` 中配置凭据并替换对应 Feature。参考 [INSTALL_ZH.md](../../INSTALL_ZH.md) 的「可选基础设施服务」一节。
